### 3. Matrix Addition
Takes two 3×3 matrices as input using separate 2D arrays, adds their corresponding elements using nested loops, stores the result in a third matrix, and displays both input matrices and the sum matrix.

### 4. Student Marks Analysis
Stores the Mid and Final marks of 4 students in a 2D array (each row is a student). Calculates and displays:

- Total marks of each student (Mid + Final)
- Highest marks in Mid, Final, and overall
- Lowest marks in Mid, Final, and overall
- Average of Mid marks and Final marks separately
