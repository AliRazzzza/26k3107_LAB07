# Programming Fundamentals InLab 07

## Topics Covered

- 2D arrays
- Nested loops
- Pattern printing
- Matrix type checking

## Programs
### 1. Shopkeeper Billing System
Stores quantity and unit price of 5 products in a 2D array. Calculates the total price of each product (`quantity × price`), displays all details, and prints the grand total.

### 5. 3×3 Matrix Types
Takes a 3×3 matrix as input and checks whether it is a:

- Square Matrix
- Null Matrix
- Upper Triangular Matrix
- Lower Triangular Matrix
